# APEE Restelo · Matilde Lino Fernandes

Site da candidatura de Matilde Lino Fernandes à presidência da APEE (Associação
de Pais e Encarregados de Educação) da Escola do Restelo, Belém — Plano de
Atividades 2026/2027.

Site estático (HTML/CSS/JS puro), sem dependências de build.

## Publicar com GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save.

O site fica disponível em `https://xtvback.github.io/APEE-Matilde/`.

## Desenvolvimento local

```
python3 -m http.server 8000
```

e abrir `http://localhost:8000`.
